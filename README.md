# neocode24 Homebrew Tap

## Usage

```bash
brew tap neocode24/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| [veil](https://github.com/neocode24/Veil) | Blank other monitors when fullscreen video is detected |

## Install

```bash
brew tap neocode24/tap
brew install --cask veil
```
